1.  Scope

This sample demonstrates the paths-bearing OpenAPI corpus: the normative sections below are generated from the bundled OGC API — Tiles OpenAPI 3.0 definition (copied verbatim from the opengeospatial/ogcapi-tiles release artifacts) through metanorma-plugin-openapi and lutaml-openapi, exercising the 3.0 normalization path and the Paths renderer.
